# SakitaGYNUSreporter

Gynecologic ultrasound reporter (O-RADS US v2022, IOTA 2026 terms, FIGO 0–8, MUSA) with an interactive 3D pelvis model.

**Open / install:** https://sakitamfm-bot.github.io/SakitaGYNUSreporter/

- **iPhone / iPad:** open the link in Safari → Share → Add to Home Screen. Open it once from the Home Screen while online; after that it works with no internet.
- **PC (Edge / Chrome):** open the link → menu → Apps → Install. Works offline afterwards.

Everything runs on the device. Data you enter is stored only in that device's browser storage and is never sent to this site.

Decision-support aid only; not a substitute for clinical judgement.
